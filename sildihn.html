ポンポン③ 8個＋洗い壺 game8式

2行×4列の8個 → 壺3個が北→南へ直進し通った3列＝6個が無属性化。壺が来ない1列の2個だけ避ける。

北に壺が無い列へ→残り2個を回避→6個を氷化→北壁際の足元
  • すべシャン(氷)で無属性6個を全部氷に／対象者はボス反対側から6個を貫くライン
  • 仕上げは本体が風 → ボスを北の壁際へ寄せ、その足元
①壺3本／残る1列 ②暗い所＝安置 ③6個氷化後

すべってシャンプーボム

非T1名へ直線頭割り。並び＝先頭 T ＞ 他 ＞ 対象者。

  • 雷：着弾後にX字＋各自小円 → ボス正面=T／背後=H／左右=D
  • 風：ノックバック → アムレン／堅実魔でボス直下、着弾後ドーナツ
  • 氷：止まっていると凍結 → 動きながら受け、その後は斜めへ

カーペットビーター＝T強攻撃。水拭き＝正面90度×2→225度。最初に倒れた側が安置、当たった玉は本体属性になる。

ポンポン② 4個・線誘導 じじー式 最難所

全員に線＋マーカー。消えると線の方向へ玉が転がる。じじー式は本体の属性に関係なく1ルール。

  • 雷（黄）＝中央から外周へ、まっすぐ引く（玉が角なら斜め外／縦横なら真っ直ぐ外）
  • 氷（青）＝時計回りに斜めへ引く。玉の斜めに立って線を伸ばす
  • ※氷は角（コーナー）へ持っていくのは絶対NG。角になりそうならさらに時計回りにずらす
  • 方向さえ合っていれば距離は不問（マス目の交点に乗らなくてよい）
  • ルールは単純だが安置が狭いので、近接は無理に殴らない
じじー式 公式チャート／左列=ボス氷・右列=ボス風、上段=四角・下段=十字

ポンポン① 3個＋水拭き game8式

水拭きで2個が風になり安置が消える → 頭割りで緑を1個だけ青（氷）に塗り替えて安置を作る。

頭割りで緑を巻き込む→Tは残った風ポンへ誘導→みんなで爆発
  • 頭割り位置：風が残れば南／雷が残れば北

ポンポン④ 氷4個・縦一列 じじー式

前段にダストブロワー（アムレン／堅実魔）。氷4個が中央の縦一列、全員に線。

  • ①全員ボス背面＝北のマス目の交点に集合（線が真北を向き斜めにならない）
  • ②⚠倒れたら即、倒れた側へ一マス⚠＝左に倒れたら一つ左の交点／右なら一つ右の交点
  • ③玉の円を踏まないよう北へ一マス（一拍おく）
  • ④最後はボス正面＝北、ヒットボックス内に集合
中央の縦一列／左に倒れたので一つ左のマスの交点へ（右なら右）

亡念幻身 → 大剛の突撃

分身2体が対角へ突進 → 前方180度 → 続けて後方180度。2体の隙間の90度が安置。

  • ラインに目盛り3つ＝停止位置。オレンジに光った回数＝止まる番号
  • アナザーはゲージ非表示。光り方だけで数える
  • 1発目を避けた場所の対面が2発目の安置
  • 組合せは1-2／1-3／2-3の3種のみ（左右は入れ替わる）。2-3は安置が最も狭い
  • 2-3処理のときは数字マーカーが目印
1-3処理／2-3処理　紫＝斬撃・白い隙間が安置

闘人砲 → 闘人の斬撃

H対象の直線頭割り。並びはボス側から T → D → H。

対象のHが最後尾にいないと死ぬ。回復も厚めに。

闘人の斬撃＝T強攻撃＋前方範囲。他は前に立たない。この後ボスを中央やや南へ。

呪怨の咆哮 ＋ 大剛の旋撃

デバフの秒数が短い方が先に発動。「頭割り＋連呪」が先か「全員散開」が先かを秒数で判断。

  • 呪怨の残響＝全員。0で自分中心の円。重なると即死
  • 重怨の残響＝1名。頭割り円
  • 連呪の残響＝1名。円＋その場に連続着弾→着弾後は離れる
  • 大剛の旋撃＝同心円3つ。チャージ完了したリングが即死 → その後反転側にもう1発（ドーナツを忘れがち）
  • 配置例：連呪=北／頭割り=南、無職2名は頭割りの両脇→立っていた方向へ散開

呪像起動＋亡念励起＋座下隆起

  • 像の顔から光の玉が出ている方にビーム。床予兆が出ないので目視
  • 亡念励起＝格子状の直線。予兆が出た順に発動→潰れていない床へ
  • 座下隆起＝マーカー消滅で円＝実質全員散開。4分割して1人1面
  • 優先度 北 T ＞ D1 ＞ D2 ＞ H 南

呪怨呪像（あえて当たる）

カウント0までに消せないと強制即死。

  • 黄金の呪い → 銀のビーム／白銀の呪い → 金のビーム（逆の色）
  • 内訳固定：金2が1名／銀2が1名／金銀1つずつが2名
  • 金2＝銀2本の交差点／銀2＝金2本の交差点／金銀＝交差点2ヶ所
  • 金銀の2名は南北に分かれて同じ場所へ行かない

ワープ床の大原則

  • 床は紫線で対になる床と繋がる。上の火球やプレイヤーは対の床へ転移
  • 「転移の呪印」で床のセットが90度回転。爆発は回転後
  • 手順：①回転の向き → ②90度回した後の火球位置 → ③紫線の相方へ飛ばす。その着地点が危険
  • 色名は表記ゆれあり。「2つが同じ回転か違う回転か」で判断が安全

呪具① 回転火球＋豪衝

杖＋火球のペアが北2組・南2組。散開は北=T+H／南=DPS。

  • 違う向き＝簡単：近接は両方に挟まれる位置、遠隔は斜め後ろの端ギリギリ
  • 同じ向き＝難しい：遠隔は端ギリギリ、近接は爆発の届く距離を体感で

呪具② 番号線切り＋影火呪式

南北に赤線4本／東西に青線4本。全員に1〜4の呪印。

絶対ルール：必ず 1 → 2 → 3 → 4 の順。順番を無視するとスタン＋ワイプ。

魔法陣が北→赤から/西→青から
  • 理由：線が安置への通せんぼ。進行方向を塞ぐ側から消す
  • 立ち位置：1回目を切るとき2回目も切れる位置に付く。2人ずつに分かれる
  • 小技：1番は発動前から線に触れておく／4番は最後の1本なのでどこからでも
  • 影火呪式＝扇が順に着弾。遅く伸びる方に立ち、1発目発動後にそこへ入る

呪具③ 呪具流火＋強制転移 eis式

回る予兆の後 最も近い2名へ扇。強制転移で任意移動が不可。

  • オレンジ(時計回り)=北半分／青(反時計)=南半分
  • 矢印が左=外側（外周端）／右=内側
  • 結果、北から南へ「左・右・右・左」が理想形
  • 転移後は内向きの床に順序を崩さず乗る。外向きに乗ると場外＝死
  • 誘導：内側=杖の左／外側=杖の真南
  • 時短技：フィールドマーカー1番・3番の上に立つと「最も近い2名」が固定できる
  • 転移で内外が入れ替わる → 1回目と同じ位置取りをもう一度
北から 左・右・右・左／北2人=オレンジ(時計回り)・南2人=青(反時計)／矢印＝乗る転移床

全体・単体技

  • 勇士の咆哮＝強力な全体。零式は軽減2枚以上
  • 石火豪衝＝ジャンプ円＋被魔法増。対象外が巻き込まれるとノックバックで即死。2発
  • 天の聖火＝直線貫通。デバフ持ちが先頭だと即死 → デバフなし2名が前で庇う。2回目はタンク無敵で縦一列
  • 石火豪打＝T対象の扇。向いている方向に近づかない

呪具④ 立体魔法陣3つ おもち式

最大の罠：回転しても「向き（角度）」は変わらない。床が回ってスライドするだけ。

  • ①西=T+H／東=DPSで魔法陣の前に待機
  • ②回転方向が出たらその回転とは逆のマスへ → その横列が安置確定
  • ③中央を確認：初期が横＝東西を分断→遠隔が対岸へ／縦＝列そのまま、ボスに近い方を近接
  • 「横4列で考える」。移動は遠隔が行う
東西2つ＋中央1つ／赤帯＝直線範囲・オレンジ＝回転。西=MT・H1／東=D2・D1

呪具⑤ 線＋杖4本＋劫火

東西南北に扇の杖4本＋赤青の線。ワープ床はない。線を切ると被魔法増（約8秒）→扇誘導役と線切り役を交互に交代。

  • 初期：1・2＝中央待機／3・4＝最初に光った杖の両脇
  • 誘導の向き：杖からボスを正面に見て 奇数=左／偶数=右
  • ①3・4が1発目の杖を挟んで誘導 → ②その間に1・2が自線を切って道を開ける
  • ③3・4が次の杖側で線を取る → ④同時に1・2が2発目の杖を誘導
  • 劫火＝全員の足元に円。中央を空けて捨てる
杖4本の扇（蝶型）＋赤＝縦の線／青＝横の線。四角＝自分の番号。誘導は奇数=左／偶数=右
