# FF14 カンペ置き場

FF14 クリテリオンダンジョン（アナザーダンジョン）用の、**戦闘中に見る想定のカンペ**です。
個人用メモとして GitHub Pages で公開する前提の、静的HTMLだけの構成になっています。

| ページ | 内容 |
| --- | --- |
| [`sildihn.html`](sildihn.html) | 異聞シラディハ水道（シルキー / シラディハ・グラディアトル / 影火のゼレズ・ガー） |
| [`rokkon.html`](rokkon.html) | 異聞六根山（獅子王 / 鉄鼠ゴウライ / 怨霊モウコ） |

## 特徴

- **1画面固定**。スクロールなしで全ギミックが並ぶので、戦闘中にマウス操作が不要
- **タブでボス切替**。`0` `1` `2` `3` キーでも切替可能
- **図はクリックで全画面拡大**（`Esc` で閉じる）
- 実際のゲーム画面・攻略図を**各ギミックのカード内**に配置（シラディハ10点／六根山21点）

## 採用している式

| 対象 | 式 |
| --- | --- |
| シラディハ 1ボス 全般 | game8 ベース |
| シラディハ 1ボス ポンポン創出 ②④ | **じじー式（Zizie）** |
| シラディハ 3ボス 呪具③ | eis式 |
| シラディハ 3ボス 呪具④ | おもち式 |
| 六根山 2ボス 般若湯（サイコロ） | Spell式 |
| 六根山 2ボス 変現呪珠の印 | ぽしうめ式 |

散開位置・左右の割り当ては固定PTのマクロによって変わります。**式を変える場合は該当カードのテキストと図を差し替えてください。**

## GitHub Pages で公開する

1. このフォルダーの中身をリポジトリ直下に置いて push
2. リポジトリの **Settings → Pages** で以下を選択
   - Source: `Deploy from a branch`
   - Branch: `main` / Folder: `/(root)`
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

`.nojekyll` を含めているので、Jekyll のビルドは走りません（`assets/` 配下がそのまま配信されます）。

## ファイル構成

```
.
├── index.html            … 入口（2つのカンペへのリンク）
├── sildihn.html          … 異聞シラディハ水道
├── rokkon.html           … 異聞六根山
├── assets/
│   ├── sildihn/          … シラディハの図（10点）
│   └── rokkon/           … 六根山の図（20点）
├── .nojekyll
└── README.md
```

HTML は画像を外部ファイル参照にしてあるので、**図の差し替えは `assets/` 配下のPNGを同名で上書きするだけ**で反映されます。

## 注意

- 攻略情報は Game8 / ARUTORA / イディルシャイア居住区 などの攻略サイト、および各解説動画を参照して再構成した**個人用メモ**です
- パッチによってギミックや推奨処理が変わることがあります
- 図の一部は攻略サイト・解説動画のスクリーンショットです。**個人利用の範囲で使用してください**
