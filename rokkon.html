01獅子王霧の回数を数える／南を先に見る／幽霊は対角

六条放雷　最重要

霞食いで黒霧を食べた回数＝直線本数。

  • 1本：黒霧のない側
  • 2本：霧なし側 → 1本目の跡地 → 次の跡地
  • 3本：2・3本目が交差する安置 → 1発目跡地 → 外周沿い

3本はスプリント。大円の着弾を見てから移動。

輪・ユウキ

獅子王牙：先に南を見る。南の輪が東ならB側安置。

不気味な呪声：中央を向く2体の対角側へ。1体目でデバフ①、2体目着弾で②。

散開 or ペア頭割り（PTマクロ優先）。

渦雷の連舞

覚えるのは2つだけ。

散開 / 頭割りの順＋円 / ドーナツの順
  • 円：外　／　ドーナツ：中
  • 頭割り基本：北T・南D
  • 散開基本：タゲサ内の担当位置

輪転渦雷：タゲサ内へ。

黒赤招魂

幽霊円8回＋大円2人＋塔2本。

  • 印なし：幽霊を避けながら塔
  • 大円あり：対角へ線を伸ばし、他人から離れる

近接欲張り禁止。

通常技・終盤

  • 猿叫：全体軽減
  • 霊鳴砲：T直線 → 背面扇。背面組は側面へ
  • 落雷：予兆を1本ずつ見る。連続でも焦らない
  • 雷雲生成3：再び霞食い回数を確認
  • 落雷2：外周雲から太い直線

02鉄鼠ゴウライ丸桃＝拡大／三角青＝拡散　Spell式・ぽしうめ式

岩火招来・琵琶

  • 丸ピンク＝拡大：岩は大円／火線が太る
  • 三角青＝拡散：岩はドーナツ／火が内→外へ分裂

炎流：自分の位置へ扇×2。1発目後に移動。

乱火2＋襲雷：散開と頭割りの予兆順を守り、エクサの進行方向へ寄らない。

招雷 → 打ち出の小槌

  • H四隅の雷球で小さくなり安置作成
  • THの前でビームを受けTH頭割り
  • Dビーム即死。射線外へ

変現の呪い　線と塔

ウソウソ青／モモンガ赤。1・3組と2・4組。

南集合→2/4 線→1/3 自色塔→交互に計4回→南西/南東

1・3組は最初タゲサ外。担当順を崩さない。

般若湯（Spell式）

① 自番号マーカー→堅実/アムレン→BD横一列

1番から番号順に前へ出て十字を捨てる。中央攻撃後は南西・南東。

二度漬け厳禁。

変現呪珠（ぽしうめ式）

デバフⅠと逆側で塔出し→対面の自色塔→四隅→呪珠印の塔
  • 異色時＝1番目と同色／同色時＝1番目と逆色
  • 全員同色なら赤塔＝左、青塔＝右
  • 最後の網目範囲×2まで見る

煩熱：T強攻撃＋火傷。バフ。

03怨霊モウコ火＝外／水＝内　270度は線対象の向き基準

霞三段　基本則

頭上予兆の色で3回の安置を判断。

  • 火＝外（タゲサ内が円で潰れる）
  • 水＝内（ドーナツ）

1発目は見て動く。2・3発目だけ覚える。カメラを回す。

赤帝 → 祈請 → 居合

赤帝：外→×字＋南北横一閃→ペア/散開

線対象の向き基準で270度。赤帝安置側へ向きを調整し、角の安置で処理。

祈請：D＋T/Hのペア頭割り、または一人受け散開。

幻影呼び①

巨腕2体 → 安置2ヶ所。近間/遠間で線担当が逆転。

  • 近間当て：ボスに近い2人がバインド。線担当は安置外、無職は内側
  • 遠間当て：役割を逆にする
  • 無職はバインド解除後、2発目安置へ
  • 居合二段の1発目は下確定
  • 線持ち：赤は外／青は内

線を無職へ当てない。

青帝 → 霞三段

青帝＝内。空閃刃は内→外へ展開。直後の霞三段も同時に見る。

屍兵 → 幻影呼び②

青い矢の着弾点で安置2択→2ペアで背を向ける
  • 幻影4体から全員へ線
  • 居合二段：1発目＝背面側
  • 2発目＝中心側。左右も判別

剣気解放：全体軽減。
胴薙ぎ：T強攻撃、バフ。
